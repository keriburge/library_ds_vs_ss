# Overview of the folder `00-documentation`
This folder contains documentation and metadata tables for samples in this project.


- `dsvss_sample_coordinates_ages.csv`: Geographic coordinates and ages of all samples included in this study
- `controls_metadata.csv`: Sample metadata for all control samples (bone samples, library blanks, and extraction blanks) included in the study
- `dsvss_gtdb_r207_species_sources.tsv`: GTDBr207 species lists with isolation source (oral or other)
- `dsvss_oral_kraken2_taxIDS.tsv`: Kraken2 taxIDs for oral-associated taxa
